# Change Default Language

The default language is changed from the **Admin Panel**, not from the mobile app code.

## Steps

1. Login to the Admin Panel.
2. Go to **Settings → Languages**.
3. In the language list, find the language you want as default.
4. Click **Set Default** (star icon) for that language.
5. The selected language will become the default (shown with a green check under **Default**).
